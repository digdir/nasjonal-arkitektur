Verdistrømmer og prosesser ()
Verdistrømmer og prosesser beskriver hvordan Nasjonal arkitektur brukes i ulike arbeidsflyter, beslutningsprosesser og utviklingsløp. Nasjonal arkitektur skal være et kunnskapsgrunnlag og en verktøykasse som kan gjenbrukes i både strategiske og operative sammenhenger. Strategiske verdistrømmer kan handle om å sette retning, prioritere tiltak, vurdere gap og beslutte felles utvikling. Operasjonelle verdistrømmer kan handle om tjenesteutvikling, produktutvikling, arkitekturarbeid, analyse av kapabiliteter og vurdering av relevante ressurser. Verdistrømmer og prosesser er derfor ikke en del av kjernemetamodellen, men viser hvordan modellen anvendes.
