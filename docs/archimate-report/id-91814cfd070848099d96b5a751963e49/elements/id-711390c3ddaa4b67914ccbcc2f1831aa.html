Sanntidsdata ()
Evne til å sikkert prosessere og distribuere kontinuerlige datastrømmer for å muliggjøre sanntidsinnsikt, automatisering og umiddelbar respons. ### Begrunnelse (Hvorfor) Kapabiliteten gjør det mulig å bruke data mens de oppstår, ikke først etter at de er samlet inn, lagret og analysert i etterkant. Den løser behovet for umiddelbar innsikt, automatisering og rask respons i tjenester og prosesser som er avhengige av kontinuerlige datastrømmer fra sensorer, tingenes internett (IoT) og andre hendelseskilder. ### Hva det innebærer (Omfang) - **Juridisk (Middels vekt):** Avklare behandlingsgrunnlag, formål, tilgang, lagringstid og ansvar når sanntidsdata inneholder personopplysninger, sikkerhetskritisk informasjon eller andre beskyttede data. - **Organisatorisk (Høy vekt):** Etablere rutiner for overvåking, varsling, hendelseshåndtering og operativ oppfølging når sanntidsdata brukes i tjenester, beslutninger og automatiserte prosesser. - **Semantisk (Høy vekt):** Sikre felles forståelse av datastrømmer, måleverdier, hendelser, tidsstempler, lokasjon, kvalitet og metadata, slik at sanntidsdata tolkes korrekt på tvers av systemer og virksomheter. - **Teknisk (Svært høy vekt):** Tilby data fra sensorer, tingenes internett (IoT) og andre hendelseskilder gjennom skalerbar infrastruktur for strømming, prosessering, filtrering, sikker distribusjon, overvåking og feilhåndtering. ### Bidrag til sammenhengende tjenester og felles økosystem Sanntidsdata gjør det mulig å reagere på endringer idet de skjer. Det gir grunnlag for automatiserte varsler, dynamisk ressursstyring, løpende situasjonsforståelse og tjenester som tilpasser seg brukerens eller samfunnets behov i øyeblikket. Kapabiliteten styrker sammenhengende tjenester ved at flere aktører kan bygge på samme oppdaterte situasjonsbilde. For sluttbrukeren kan dette gi raskere respons, mer presis veiledning og tjenester som oppleves mer relevante og proaktive. For det felles økosystemet gir det bedre datadrevet styring, mer effektiv samhandling og økt evne til å håndtere hendelser på tvers av virksomheter.
