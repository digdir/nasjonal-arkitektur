Dele data med andre ()
Evne til å tilgjengeliggjøre egne data som veldokumenterte og sikre API-er, slik at andre aktører med lovlig grunnlag enkelt kan oppdage og gjenbruke dem. Dette innebærer: Å etablere og forvalte sikre API-er etter nasjonale standarder. Å publisere og dokumentere dataene i Felles datakatalog, slik at de blir lette å finne og forstå. Å ha robuste systemer for tilgangsstyring som sikrer at data kun deles med de som har lov til det (f.eks. via Maskinporten).
