P6: Lag digitale løsninger som støtter samhandling ()

Digitale løsninger skal utvikles slik at de kan samhandle med andre løsninger i offentlig og privat sektor. Det krever juridisk, organisatorisk, semantisk og teknisk samhandlingsevne, blant annet standardisering, avtaler og felles begrepsapparat.

Begrunnelse: Samhandlingsvennlige løsninger er en forutsetning for sammenhengende tjenester og tverrgående prosesser, realisert på en fleksibel og kostnadseffektiv måte.

Kjennetegn ved etterlevelse:

  • Løsningen er utformet for samspill med andre løsninger, både ved egenutvikling og ved anskaffelse.
  • Obligatoriske standarder i forskrift om IT-standarder i offentlig forvaltning følges, og ellers brukes anbefalte eller andre åpne standarder.
  • Norsk arkitekturrammeverk for samhandling er brukt når tjenesten skal inngå i samhandling med andre virksomheter.
  • Det finnes avtaler mellom samhandlingspartene om informasjonssikkerhet, personvern, tjenestekvalitet og samhandlingsevne.
  • Informasjonsutvekslingen har ytelse som gjør at brukerne opplever tjenestene som oppdaterte, og løsningen kan skalere ved endret bruk.
