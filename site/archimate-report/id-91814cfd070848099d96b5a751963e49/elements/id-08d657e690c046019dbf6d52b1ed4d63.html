Ustrukturerte data ()
Evne til å tilgjengeliggjøre og forvalte data som ikke er påført en forhåndsdefinert struktur. ### Begrunnelse (Hvorfor) Kapabiliteten gjør det mulig å lagre, organisere, finne, forstå og bruke data som ikke passer i tradisjonelle strukturer. Dette gjelder for eksempel fritekst-dokumenter, e-poster, bilder, lydopptak, video og råe loggfiler. Ustrukturerte data er ofte i sin opprinnelige form. Kapabiliteten løser behovet for å gjøre slike data tilgjengelige og forvaltbare, slik at de kan brukes til innsikt, saksbehandling, automatisering, analyse og utvikling av mer sammenhengende tjenester. ### Hva det innebærer (Omfang) - **Juridisk (Høy vekt):** Avklare behandlingsgrunnlag, lagringstid, tilgang, taushetsplikt, personvern og arkivkrav når ustrukturerte data inneholder personopplysninger, saksinformasjon eller annen beskyttet informasjon. - **Organisatorisk (Høy vekt):** Etablere rutiner for innsamling, klassifisering, kvalitetssikring, tilgangsstyring, bevaring, sletting og bruk av ustrukturerte data i arbeidsprosesser. - **Semantisk (Høy vekt):** Bruke metadata, klassifikasjoner, emneord, begreper og kontekstbeskrivelser som gjør ustrukturerte data finnbare, forståelige og gjenbrukbare. - **Teknisk (Høy vekt):** Tilby kapasitet til å lagre, indeksere, søke i og prosessere ustrukturerte data som fritekst-dokumenter, e-poster, bilder, lydopptak, video og råe loggfiler. Dette krever sikre lagringsløsninger, søketeknologi, tilgangskontroll og verktøy for analyse og maskinell behandling. ### Bidrag til sammenhengende tjenester og felles økosystem Ustrukturerte data gjør det mulig å utnytte informasjon som ellers ville blitt liggende utilgjengelig i dokumenter, e-poster, logger, bilder eller andre frie formater. Når slike data kan forvaltes, beskrives og brukes på en sikker og strukturert måte, får virksomhetene et rikere grunnlag for saksbehandling, analyse og tjenesteutvikling. Kapabiliteten styrker sammenhengende tjenester ved å gjøre relevant informasjon lettere å finne og bruke på tvers av prosesser og virksomheter. For sluttbrukeren kan dette gi bedre veiledning, raskere behandling og mer helhetlig oppfølging. For det felles økosystemet gir det bedre kunnskapsutnyttelse og økt verdi fra data som tidligere var vanskelig å dele og gjenbruke.
