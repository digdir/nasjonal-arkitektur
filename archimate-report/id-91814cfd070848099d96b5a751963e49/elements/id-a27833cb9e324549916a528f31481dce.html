P4: Del og gjenbruk data ()

Virksomheter skal legge til rette for deling og gjenbruk av data. Data er en fellesressurs som gir store gevinster for forvaltningen, innbyggere, næringsliv og frivillige organisasjoner når de deles og gjenbrukes.

Begrunnelse: Deling av offentlige data gir økt kunnskap, verdiskaping, innovasjon, effektivitet og åpenhet. Det er en forutsetning for effektive arbeidsprosesser, sammenhengende tjenester og automatisering, gjør at brukerne slipper å oppgi informasjon det offentlige allerede har (kun én gang), og kan gi bedre datakvalitet.

Kjennetegn ved etterlevelse:

  • Relevante data gjenbrukes, og egne data legges til rette for deling, når tjenester etableres eller videreutvikles.
  • Data hentes fra autoritative kilder; kopier brukes bare der det er nødvendig og holdes oppdatert.
  • Data tilbys i tråd med regjeringens retningslinjer for tilgjengeliggjøring av offentlige data.
  • Datasett, API-er, begreper og informasjonsmodeller er beskrevet i Felles datakatalog.
  • Data er ikke låst i systemspesifikke formater, og egne data forvaltes etter Rammeverk for informasjonsforvaltning.
