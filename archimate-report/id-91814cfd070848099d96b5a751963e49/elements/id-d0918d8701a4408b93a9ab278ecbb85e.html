P5: Del og gjenbruk løsninger ()

Deling og gjenbruk av løsninger omfatter arkitekturprodukter, løsningskomponenter og tjenester, på nasjonalt, sektorielt og virksomhetsnivå.

Begrunnelse: Deling og gjenbruk fremmer samhandlingsevne, innovasjon og effektivitet, og bidrar til harmonisering, informasjonssikkerhet og personvern. Virksomhetene kan da konsentrere seg om å digitalisere kjernevirksomheten i stedet for å løse utfordringer som allerede er løst.

Kjennetegn ved etterlevelse:

  • Eksisterende og planlagte løsninger som kan gjenbrukes, er kartlagt.
  • Fellesløsninger og felleskomponenter brukes der de er egnet for formålet.
  • Markeds- og skyløsninger er vurdert før egenutvikling, og bindinger til enkeltleverandører er vurdert.
  • Arkitekturen gir endrings- og vedlikeholdsevne over tid, blant annet gjennom løse koplinger, modularisering, standardiserte tjenestekontrakter og redusert kompleksitet og teknisk gjeld.
  • Egne løsninger som kan være nyttige for andre, er gjort kjent og tilbudt for gjenbruk, og forbedringsinnspill gis til forvalterne av løsninger som brukes.
