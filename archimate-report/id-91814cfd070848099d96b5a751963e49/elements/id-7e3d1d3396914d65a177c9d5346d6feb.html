Sammenstilling av data ()

Evne til å hente, kombinere og foredle data fra ulike kilder for å skape ny innsikt, et helhetlig beslutningsgrunnlag, eller sammenhengende tjenester for brukeren.

Begrunnelse (Hvorfor)

Kapabiliteten gjør det mulig å skape ny verdi ved å kombinere data fra flere kilder. Den løser problemet med at beslutninger, analyser og tjenester ofte bygger på fragmenterte datagrunnlag som ikke gir et helhetlig bilde av brukerens situasjon, virksomhetens behov eller en tverrgående tjenestekjede.

Hva det innebærer (Omfang)

  • Juridisk (Middels vekt): Avklare behandlingsgrunnlag, formål, tilgangsrettigheter, dataminimering og ansvar når data fra ulike kilder kombineres.
  • Organisatorisk (Høy vekt): Etablere rutiner for å identifisere relevante datakilder, avklare eierskap, sikre kvalitet og bruke sammenstilte data i beslutninger, analyser og tjenesteprosesser.
  • Semantisk (Svært høy vekt): Harmonisere begreper, metadata, klassifikasjoner, informasjonsmodeller og datakvalitet slik at data fra ulike kilder kan tolkes korrekt samlet.
  • Teknisk (Høy vekt): Bruke standardiserte grensesnitt, dataplattformer, integrasjonsmønstre og behandlingsløp for å hente, koble, transformere og foredle data på en sikker og sporbar måte.

Bidrag til sammenhengende tjenester og felles økosystem

Kapabiliteten gjør det mulig å bygge tjenester og beslutningsgrunnlag på et helhetlig databilde, ikke bare på opplysninger fra én virksomhet eller ett system. Når data kan hentes, kombineres og foredles på tvers, blir det enklere å forstå brukerens situasjon, forutse behov og tilby mer treffsikre tjenester. For det felles økosystemet bidrar kapabiliteten til bedre datadrevet styring, mer gjenbruk av eksisterende data og mer sammenhengende tjenestekjeder.
