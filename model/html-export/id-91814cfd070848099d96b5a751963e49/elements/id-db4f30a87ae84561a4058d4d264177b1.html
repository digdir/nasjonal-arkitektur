Åpne data ()

Evne til å tilgjengeliggjøre åpne data slik at den kan leses og tolkes av både maskiner og mennesker, og som alle kan få tilgang til, bruke og dele.

Begrunnelse (Hvorfor)

Kapabiliteten utvider verdien av offentlige data utover forvaltningens egne grenser og gir avkastning i hele samfunnet. Åpne data styrker demokrati og åpenhet ved å gi innbyggere, journalister og interessegrupper mulighet til innsyn i forvaltningens arbeid og beslutningsgrunnlag. Dette øker transparensen og legger til rette for en mer informert offentlig debatt.

Åpne data er også et råstoff for næringsutvikling og innovasjon. Offentlige data representerer en stor ressurs som kan gi næringslivet grunnlag for å skape nye produkter, tjenester og arbeidsplasser som det offentlige ikke ville utviklet selv.

Kapabiliteten forbedrer forskning og faktabasert politikkutforming ved å gi forskere tilgang til rike datasett som kan brukes til å analysere samfunnstrender, evaluere politikk og løse komplekse samfunnsutfordringer.

Hva det innebærer (Omfang)

  • Juridisk (Høy vekt): Sikre at data kan gjøres tilgjengelig for fri bruk og viderebruk innenfor gjeldende regelverk, lisenser, personvern, taushetsplikt og krav til offentlighet.
  • Organisatorisk (Høy vekt): Etablere rutiner for å identifisere, prioritere, publisere, vedlikeholde og følge opp åpne datasett over tid, slik at andre kan stole på tilgjengelighet og pålitelighet.
  • Semantisk (Høy vekt): Sørge for at åpne data er godt dokumenterte, sporbare tilbake til kilden og beskrevet med metadata som gjør dem lette å oppdage, vurdere, forstå, dele og diskutere.
  • Teknisk (Høy vekt): Tilgjengeliggjøre data i maskinleselige, standardiserte og strukturerte formater som kan bearbeides av både mennesker og maskiner, og som kan lenkes til og brukes på tvers av løsninger.

Bidrag til sammenhengende tjenester og felles økosystem

Åpne data styrker det felles økosystemet ved å gjøre offentlige data tilgjengelige som en felles ressurs for forvaltning, næringsliv, forskning, sivilsamfunn og innbyggere. Når data er godt dokumenterte, maskinleselige, sporbare og pålitelige over tid, kan de brukes som byggeklosser i nye tjenester, analyser og beslutningsgrunnlag.

Kapabiliteten bidrar til sammenhengende tjenester ved at aktører utenfor den opprinnelige datakilden kan bygge videre på samme informasjonsgrunnlag. Dette gir mer åpenhet, økt innovasjon, bedre faktagrunnlag og mer effektiv gjenbruk av data på tvers av virksomheter og sektorer.
