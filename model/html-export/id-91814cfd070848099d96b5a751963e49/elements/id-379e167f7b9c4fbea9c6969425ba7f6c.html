Tjenestedesign ()
Evne til å sette brukerens behov, livssituasjon og helhetlige reise som utgangspunkt for utvikling av sammenhengende tjenester. Dette innebærer: * Å systematisk innhente og bruke kunnskap om brukernes faktiske behov, adferd og utfordringer. * Å designe tjenester som dekker hele brukerbehovet fra start til slutt, selv når løsningen krever samarbeid tverrsektorielt og ulike forvaltningsnivå.
